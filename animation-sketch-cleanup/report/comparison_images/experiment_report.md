# 动画草图线条清洗实验报告
项目：灵图数字笔试｜动画草图自动描原任务

## 1. 方法设计与选型理由
本任务目标为手绘动画草稿自动清线，剔除浅蓝、紫色辅助草稿线，保留黑色轮廓、红色高光边界、蓝色阴影边界。
本次选择 **HSV色彩分割 + 形态学图像处理 + 连通域筛选** 的传统计算机视觉方案，选型理由：
1. **轻量化无训练成本**：无需GPU、不需要数据集训练，单张图片推理速度快，适合动画批量帧处理；
2. **任务场景适配**：草稿线条依靠固定色彩区分，色彩空间分割可以精准区分辅助线与有效结构线条；
3. **可解释性强**：每一步处理逻辑清晰，参数便于调试；
4. **连续帧稳定性高**：不存在深度学习模型随机波动，保证动画序列输出一致性，避免画面闪烁。

局限：该方案依赖固定色彩阈值，泛化能力弱于深度学习方案，适合色彩规范统一的动画生产线稿场景。

## 3. 失败案例分析
1. **极淡低对比度线条丢失**
原因：算法使用固定HSV阈值，手绘线条深浅不一，饱和度较低的有效线条会被判定为噪声；同时连通域面积阈值过滤了极小的细线纹理。
2. **线条交叉区域出现局部断线**
原因：形态学开运算在消除噪点的同时，侵蚀了狭窄的线条交接区域，造成微小断裂；
3. **无法兼容色彩偏移的草稿**
原因：硬编码颜色区间，如果原画发生色彩偏差，分割效果会大幅下降。

## 4. 改进方向（≥2条）
1. **引入自适应阈值与局部对比度增强**
对图像进行CLAHE对比度增强，使用动态阈值替代固定HSV区间，提升淡色线条提取能力，增强方案泛化性。
2. **优化形态学流水线，增加断线修复策略**
调整开闭运算执行顺序，增加线条连通修补算法，平衡降噪与线条完整性；动态连通域阈值，区分大面积轮廓和细碎纹理。
3. 【进阶方案】接入LineArt预训练线条提取模型
摆脱颜色依赖，基于图像语义提取线条，适配各种色调手绘草稿。
