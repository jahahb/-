# 动画草图线条清洗实验报告
## 一、任务概述
针对动画手绘草稿实现自动描原、草稿清理。输入草图包含草稿辅助线、正式结构线条；算法自动剔除草稿杂线，保留黑色轮廓、红色高光边界、蓝色阴影边界，输出标准化干净线稿。
输入素材：A1.jpg、A2.jpg、A3.jpg连续角色原画草稿
真值素材：A1.tga、A2.tga、A3.tga人工清线标准线稿

## 二、算法实现流程
1. 图像读取，转换BGR图像至HSV色彩空间；
2. 通过色彩阈值掩码识别浅蓝色、紫色辅助草稿区域，填充白色实现擦除；
3. 分别提取黑色轮廓、红色线条、蓝色线条掩码；
4. 形态学闭运算连通断裂线条，开运算消除细碎噪点；
5. 连通域分析，过滤面积过小的噪声像素；
6. 在白色画布上重绘分层线条，输出最终规范化线稿。

## 三、实验效果整体说明
本次草图自动描原算法针对动画手绘草稿完成线稿规范化清洗任务，输入为包含浅蓝结构辅助线、紫色草稿杂线、黑色主体轮廓、红色高光边界、蓝色阴影边界的手绘原画，输出为符合规范的四色标准线稿。整体算法能够有效区分草稿辅助线条与有效结构线条，完成自动清线、去噪、结构保留与规范化输出，整体画面干净、主体结构完整，能够满足动画上色生产的基础要求。

## 四、现有算法优势
1. **辅助线清除效果良好**
算法成功识别并清除画面中低饱和度的浅蓝结构辅助线、淡紫色草稿修正线，无残留杂线、无多余涂鸦纹理，画面整洁度高。

2. **主体轮廓保留完整**
角色头部、五官、发丝、服饰、披风等主体结构线条完整，未出现大面积轮廓丢失、结构变形、构图错乱等问题，整体构图与原始草稿完全一致。

3. **语义线条区分准确**
能够有效保留黑色主体轮廓线、红色高光分界线、蓝色阴影分界线，严格遵循题目四色规范输出，语义分层清晰，符合动画原画描原的生产标准。

4. **连续帧稳定性较好**
针对 A1、A2、A3 连续动作原画，算法输出风格统一，线条粗细、干净程度保持一致，无帧间突变、闪烁、跳变问题，时序稳定性良好。

## 五、当前存在的缺陷
1. **局部轻微断线、细线条弱化**
部分手绘浅淡细线条、交接处存在轻微断裂、缺失，相比人工成品线稿，细节饱满度略有不足。

2. **极细纹理细节丢失**
头发细碎纹理、衣物褶皱超细线条在去噪过程中被轻微过滤，精细度略低于真值图。

3. **线条均匀度仍有提升空间**
局部线条存在轻微粗细不均，不如人工清线规整顺滑。

## 六、问题原因分析
当前方案基于传统HSV颜色分割+形态学后处理实现，依赖固定阈值筛选线条：
1. 手绘线条深浅、明暗不均匀，固定阈值对极淡线条适应性有限；
2. 形态学去噪为了保证画面干净，会牺牲部分超细纹理；
3. 纯颜色分割无法做到完全语义级识别，复杂交接区域容易产生微小断线。

## 七、优化改进方案
1. **引入自适应阈值与局部对比度增强**
替代固定HSV阈值，提升对深浅不一手绘线条的识别能力，保留淡色有效结构线。

2. **优化形态学操作顺序与参数**
调整先闭合、后开运算的策略，增强断线修复能力，降低细节侵蚀，提升线条完整度与顺滑度。

3. **引入深度学习线条提取方案（高阶优化）**
采用LineArt预训练模型提取主体结构，摆脱颜色阈值依赖，提升复杂草稿、弱线条、重叠线条的提取精度，进一步缩小算法输出与人工成品的差距。

## 八、整体自评总结
本次实现的草图描原算法能够稳定完成动画草稿清线任务，精准剔除辅助杂线、完整保留角色结构与语义分界线，连续帧输出稳定、规范性强。虽然在超细细节、线条顺滑度上与人工描原存在小幅差距，但整体效果满足动画生产清线需求，方案逻辑完整、鲁棒性强，可通过后续自适应优化与深度学习方案进一步提升精度。
